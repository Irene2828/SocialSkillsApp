# Design Taste — SocialSkillsApp

> Living document. Authoritative alongside the formal design system.
> Updated as visual decisions are made. Read this file before any visual review.

---

## Overall Feeling

The product should feel:

- quiet
- clear
- intentional
- intelligent
- premium without looking luxurious for its own sake
- friendly without becoming playful or childish
- visually restrained, but never empty or unfinished

---

## Typography

- Prefer regular and medium weights over bold weights.
- On small screens, heavy typography often feels cramped and cheap.
- Use bold only when hierarchy genuinely requires it.
- Do not make every section heading visually dominant.
- Body text must remain readable without feeling oversized.
- Avoid very small grey text used only to appear sophisticated.

---

## Spacing

- Spacing should feel deliberate and generous, not loose.
- Repeated components must use consistent internal padding.
- Similar sections should share the same horizontal gutters.
- Do not fix spacing only on the currently visible screen.
- Check rhythm between heading, supporting copy, content and actions.
- Avoid both crowded layouts and excessive decorative whitespace.

---

## Anti-Generic Rules

Avoid:

- default SaaS dashboard aesthetics
- unnecessary gradients
- glowing borders
- excessive rounded cards
- random glassmorphism
- oversized marketing headlines
- decorative pills without a functional reason
- generic AI sparkles
- too many competing visual accents
- motion added only to make the interface feel modern

Every visual element should support hierarchy, comprehension, action or product identity.

---

## Mobile Quality

- Mobile is not a compressed desktop layout.
- Check the interface on narrow devices.
- Avoid heavy text, cramped controls and excessive card stacking.
- Ensure tap targets remain comfortable.
- Check wrapping, safe areas, keyboard states and scrolling.
- Preserve calm visual rhythm on small screens.

---

## Product Judgment

Do not automatically redesign something because another solution looks more fashionable.

Protect:

- the current product intention
- recognizable interaction patterns
- established visual language
- user clarity
- explicitly approved decisions

When several visually valid solutions exist, present the options and ask me.
